# Ellak2026Project1-HospitalRobot
# 🏥 hospitalrobot
**Open-source ρομπότ διανομής εντός νοσοκομείου με line-following + AI όραση (HuskyLens) + QR/Barcode αποστολές**

---

## 1. Τι είναι
Το **hospitalrobot** είναι ένα **εκπαιδευτικό, open-source ρομποτικό σύστημα διανομής** που προσομοιώνει τη μεταφορά υλικών εντός νοσοκομείου (π.χ. φάρμακα, αναλώσιμα, έγγραφα).

Το ρομπότ:
- κινείται αυτόνομα ακολουθώντας **γραμμή στο πάτωμα** (line-following),
- αναγνωρίζει **δωμάτια / σταθμούς** μέσω **QR / tags** με την **AI κάμερα HuskyLens**,
- διαβάζει **QR/Barcode αποστολής** για να ξέρει τον προορισμό,
- ειδοποιεί προσωπικό (ή “καλεί βοήθεια”) όταν δεν μπορεί να ολοκληρώσει την αποστολή.

⚠️ **Σημαντικό**:  
Το project είναι **εκπαιδευτικό demo logistics**.  
Δεν λαμβάνει ιατρικές αποφάσεις και **δεν διαχειρίζεται πραγματικά φάρμακα**.

## 2. Στόχος (γιατί το κάνουμε)

Μέσα από την υλοποίηση του έργου hospitalrobot, οι μαθητές του Γυμνασίου επιδιώκεται αρχικά να αναγνωρίσουν και να κατανοήσουν βασικά κοινωνικά ζητήματα που αφορούν τη λειτουργία κρίσιμων υποδομών υγείας, καθώς και την έννοια του κοινού καλού στο πλαίσιο της σύγχρονης τεχνολογίας. Οι μαθητές θα περιγράψουν τον ρόλο της τεχνολογίας ανοιχτού κώδικα στη δημιουργία λύσεων που εξυπηρετούν συλλογικές ανάγκες και θα εξηγήσουν τη βασική λειτουργία ενός ρομποτικού συστήματος διανομής σε ελεγχόμενο περιβάλλον.

Σε επίπεδο εφαρμογής, οι μαθητές θα χρησιμοποιήσουν αισθητήρες γραμμής, κινητήρες και ενεργοποιητές για την πλοήγηση ενός ρομπότ, θα εφαρμόσουν διαδικασίες σάρωσης QR/Barcode για τον καθορισμό προορισμών και θα υλοποιήσουν απλές ρουτίνες αυτοματισμού που συνδέουν την αντίληψη του περιβάλλοντος με τη λήψη αποφάσεων. Παράλληλα, θα πειραματιστούν με τη χρήση τεχνητής όρασης μέσω της κάμερας HuskyLens, κατανοώντας πώς η AI μπορεί να υποστηρίξει πρακτικές εφαρμογές με κοινωνικό όφελος.

Σε ανώτερο γνωστικό επίπεδο, οι μαθητές θα αναλύσουν τη ροή λειτουργίας του συστήματος από τη φόρτωση έως την παράδοση μιας αποστολής, θα διακρίνουν καταστάσεις επιτυχίας και αποτυχίας και θα συσχετίσουν τεχνολογικές επιλογές με περιορισμούς ασφάλειας, κόστους και αξιοπιστίας. Στη συνέχεια, θα αξιολογήσουν την αποτελεσματικότητα του έργου ως προσομοίωση νοσοκομειακής εφοδιαστικής και θα τεκμηριώσουν γιατί το σύστημα λειτουργεί ως εκπαιδευτικό μοντέλο και όχι ως πραγματική ιατρική λύση.

Τέλος, οι μαθητές θα σχεδιάσουν και θα κατασκευάσουν ένα λειτουργικό ρομποτικό πρωτότυπο ανοιχτών τεχνολογιών, θα δημιουργήσουν σενάρια χρήσης που ανταποκρίνονται σε πραγματικές ανάγκες της κοινότητας και θα προτείνουν επεκτάσεις ή βελτιώσεις του συστήματος, λαμβάνοντας υπόψη την κοινωνική ωφέλεια, τη βιωσιμότητα και τη δυνατότητα επαναχρησιμοποίησης από άλλες σχολικές ομάδες.

Με τον τρόπο αυτό, το έργο συμβάλλει στην ανάπτυξη τεχνολογικών, κοινωνικών και συνεργατικών δεξιοτήτων και ενισχύει την αντίληψη των μαθητών ότι η τεχνολογία ανοιχτού κώδικα μπορεί να λειτουργήσει ως εργαλείο προσφοράς και θετικού κοινωνικού αντίκτυπου, σε πλήρη εναρμόνιση με τη θεματική «Ανοιχτές Τεχνολογίες για το Κοινό Καλό».

## 3. Βασική αρχιτεκτονική συστήματος

### Κινητή βάση
- **micro:Maqueen Plus** (δύο ρόδες, line sensors, DC motors)

### Αντίληψη
- **Gravity HuskyLens AI Camera**
  - **QR / tag recognition** για δωμάτια / σταθμούς
  - **QR/Barcode scan** για ανάγνωση αποστολής (προορισμός)

### Ενεργοποιητές
- Servo / μηχανισμός τύπου **φορτωτή / κλαρκ** (extension)
- **Buzzer & LEDs** (ειδοποίηση / κατάσταση)

## 4. Πώς λειτουργεί (Workflow)

### 4.1 Φόρτωση αποστολής
1. Το ρομπότ βρίσκεται στον **σταθμό φόρτωσης**
2. Σκανάρεται **QR/Barcode αποστολής**
   - περιέχει προορισμό (π.χ. `ROOM-203`)

### 4.2 Πλοήγηση
3. Το ρομπότ ακολουθεί **γραμμή στο πάτωμα**
4. Σε κάθε κόμβο/διασταύρωση:
   - η HuskyLens σκανάρει **QR marker σταθμού/δωματίου**

### 4.3 Αναγνώριση προορισμού
5. Αν το QR του χώρου = προορισμός:
   - το ρομπότ σταματά
   - ενεργοποιεί buzzer / LED
   - περιμένει παραλαβή

### 4.4 Αποτυχία / ανάγκη βοήθειας
6. Αν:
   - χαθεί η γραμμή
   - δεν αναγνωριστεί χώρος
   - υπάρξει εμπόδιο  
→ ενεργοποιείται **alert mode** (ήχος / φως) για προσωπικό

### 4.5 Επιστροφή
7. Μετά την παράδοση:
   - επιστρέφει στον σταθμό βάσης

## 9. Setup / Υλοποίηση (high-level)
1. Χάραξη γραμμής πλοήγησης στο πάτωμα (line track)
2. Τοποθέτηση QR markers σε δωμάτια / σταθμούς
3. Συναρμολόγηση Maqueen + extension (forklift/loader)
4. Σύνδεση HuskyLens
5. Προγραμματισμός:
   - line following
   - QR recognition
   - state machine (καταστάσεις)
6. Δοκιμές & βελτιστοποίηση
